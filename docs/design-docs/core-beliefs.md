# Core Beliefs

- The repository is the system of record for agents. If it is not in the repo, it does not exist.
- `AGENTS.md` is a router, not an encyclopedia.
- Verification evidence matters more than confidence. "It looks done" is not done.
- One bounded task at a time beats many half-finished tasks.
- Repeated human feedback should become reusable, mechanical rules (lints, checks).
- A clean, restartable state at session end is part of shipping, not an afterthought.
- Architectural boundaries are an early prerequisite, not a late refactor.
- Boring, stable technologies are easier for agents to reason about; prefer them.
